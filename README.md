# 📋 Class Attendance Tracker

A mobile-friendly, offline-capable attendance tracking app for educators. No installation required — runs entirely in your browser.

## Features

- ✅ **Multi-course support** — Track multiple classes with tabbed navigation
- ✅ **4 attendance statuses** — Present, Absent, Late, Excused
- ✅ **Up to 26 students per course** — With ID and email fields
- ✅ **Auto-generate class dates** — Set semester range and class days
- ✅ **Attendance statistics** — Per-student rates and daily summaries
- ✅ **Export options** — JSON backup and CSV for spreadsheets
- ✅ **Mobile responsive** — Works on tablets, phones, and desktops
- ✅ **Offline capable** — Data saves locally in your browser
- ✅ **Print friendly** — Generate paper records when needed

## Quick Start

1. Open the app in your browser
2. Click **Courses** → Add your course (code, name, section)
3. Click **Settings** → Set semester dates → **Generate Class Dates**
4. Click **Students** → Add students individually or bulk paste
5. Tap checkboxes to mark attendance (cycles through P → A → L → E)

## Data Storage

- Data saves automatically to your browser's localStorage
- **Export regularly** using the Export button (JSON for backup, CSV for spreadsheets)
- Data is device-specific — use Export/Import to transfer between devices
